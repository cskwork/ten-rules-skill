# Rule 09 — Grow by Controlled Experiments, Not Opinions

> 성장은 의견 싸움이 아니라 통제된 실험으로 결정한다.
> Growth is decided by controlled experiments, not by whose opinion is loudest.

## Why

Durable growth comes from a high-velocity loop of hypotheses tested with controlled experiments, not from one-off hunches. Sean Ellis's ICE model (Impact, Confidence, Ease) ranks ideas so limited capacity goes to the highest-leverage tests first. Statistical discipline matters: pre-calculate sample size, define the metric and minimum detectable effect up front, and wait for significance instead of peeking. Without controls and rigor, you ship noise and mistake luck for learning.

## How to apply

- Write each experiment as a falsifiable hypothesis with a single primary metric.
- Score and rank the backlog with ICE so the highest-leverage tests run first.
- Calculate sample size and minimum detectable effect before launching; avoid peeking at results.
- Use a proper control group and run the test to its predetermined end.
- Document every result, win or loss, so learnings compound across the team.

## Checklist

- [ ] Each experiment has a falsifiable hypothesis and one primary metric
- [ ] The backlog is prioritized with ICE (or equivalent)
- [ ] Sample size and significance threshold are set before launch
- [ ] A control group is used and results are documented regardless of outcome
