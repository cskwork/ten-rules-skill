# Rule 07 — Instrument the Full AARRR Funnel

> 측정하지 않는 단계는 개선할 수 없다 — 다섯 단계를 모두 계측하라.
> You cannot improve a stage you do not measure; instrument all five stages.

## Why

Dave McClure's Pirate Metrics (AARRR) gives a shared map of the customer lifecycle: Acquisition, Activation, Retention, Referral, Revenue. Without instrumentation across all five, teams optimize the visible top of the funnel and ignore where the real leak is. The framework forces a data-driven view so you can find the single stage that, if fixed, unlocks the most growth, instead of guessing. It is the default measurement scaffold for product-led growth.

## How to apply

- Define one primary metric and clear event for each of the five AARRR stages.
- Build conversion views between adjacent stages to expose the biggest leak.
- Set a measurable activation milestone (the moment a user first gets real value).
- Review the funnel by cohort and segment, not just aggregate totals.
- Prioritize the stage with the largest leverage, then re-measure after each change.

## Checklist

- [ ] Each AARRR stage has a defined metric and tracked event
- [ ] Stage-to-stage conversion rates are visible
- [ ] A concrete activation milestone is instrumented
- [ ] The highest-leverage leak stage is identified before optimizing
