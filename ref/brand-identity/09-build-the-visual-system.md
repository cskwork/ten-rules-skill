# Rule 09 — Build a Visual Identity System

> 로고 하나가 아니라, 함께 작동하는 시스템을 설계하라.
> Design a system that works together, not a single logo.

## Why

Marty Neumeier (The Brand Gap) frames identity as a system: logo, color, type, imagery, and layout that work together and flex across media, not one fixed lockup. The visual system is the carrier of the distinctive brand assets that drive recognition (Ehrenberg-Bass), so each element must be chosen for distinctiveness and reproducibility. A system designed only for one hero application breaks the moment it meets a favicon, an app icon, or a billboard. Build for range and recognition from the start.

## How to apply

- Define the logo with clear-space, minimum-size, and approved-variation rules for each context.
- Choose a focused color palette with accessible contrast and specified values per medium (digital, print).
- Select a type system with a clear hierarchy and licensed fonts for all platforms.
- Specify imagery style, iconography, grid, and spacing so layouts stay coherent.
- Pick the most distinctive element as the anchor and protect it most strictly.

## Checklist

- [ ] Logo rules cover clear-space, minimum size, and approved variations
- [ ] Color palette has defined values per medium and meets contrast requirements
- [ ] A licensed type system with hierarchy is specified
- [ ] Imagery, icon, and grid rules keep layouts coherent across media
