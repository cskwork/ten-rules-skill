# Rule 06 — Consistency Builds Recognition

> 일관성이 곧 인지도다. 반복이 기억을 만든다.
> Consistency is recognition; repetition builds memory.

## Why

Recognition is the cumulative result of repeated, consistent exposure to the same assets, the mechanism behind Ehrenberg-Bass distinctive brand assets and Aaker's brand equity. Each consistent impression strengthens the memory link; each inconsistent or restyled one resets it and wastes prior investment. Frequent redesigns and channel-by-channel improvisation are how brands stay invisible. Treat consistency as compounding interest on every prior impression.

## How to apply

- Apply the same core assets, voice, and proportions across every touchpoint and over time.
- Resist novelty-driven redesigns; evolve assets gradually so memory links are not broken.
- Give every team and partner the canonical assets so executions do not drift.
- Audit live touchpoints regularly for divergence and correct it.
- When evolving identity, retain the strongest distinctive assets through the transition.

## Checklist

- [ ] Core assets, voice, and proportions match across all touchpoints
- [ ] Redesigns evolve rather than reset the strongest assets
- [ ] All teams and partners use the same canonical asset source
- [ ] A periodic consistency audit runs across live touchpoints
