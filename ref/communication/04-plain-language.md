# Rule 04 — Plain Language

> 짧고 쉬운 말로 써라.

## Why

어려운 표현은 전문성을 보여주는 게 아니라 이해 비용을 높인다. Gowers 의 *Plain Words* 는 “짧게, 단순하게, 인간적으로”를 강조하고, US plainlanguage.gov 는 일상어 · 능동태 · 직접 구조를 권고한다.

## How to apply

- 긴 명사구 → 동사로 풀어쓴다. (“조치의 이행” → “실행한다”)
- 수동태 → 능동태로. (“보고서가 제출될 예정” → “저희가 내일 제출합니다”)
- 전문어 / 약어 / 영어 외래어를 청중 기준으로 검토.
- 한 문장에 한 가지 생각 — 마침표를 두려워하지 마라.
- 사람을 등장시킨다. “시스템이 처리한다”보다 “저희 팀이 처리한다”.

## Anti-patterns

| Bad | Better |
|-----|--------|
| 조치가 이행될 예정입니다 | 저희가 다음 주에 실행합니다 |
| 이슈가 식별되었습니다 | 문제를 찾았습니다 |
| 해당 사안에 대하여 | 이 건은 |

## Checklist

- [ ] 평균 문장 길이가 짧다 (한 문장에 한 생각)
- [ ] 수동태·명사화 표현을 줄였다
- [ ] 전문어/약어를 청중 기준으로 풀거나 정의했다
- [ ] 사람(주어)이 분명히 드러난다
