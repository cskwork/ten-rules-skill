# Rule 06 — Honest About Uncertainty

> 신뢰를 위해 불리한 사실과 불확실성도 말하라.

## Why

신뢰는 완벽한 말투가 아니라 정직한 정보 구조에서 나온다. CDC CERC 는 위기 상황에서 “알려진 것과 모르는 것을 모두 말하라”고 권고하고, Warren Buffett 의 Berkshire Owner’s Manual 은 “입장이 바뀌었을 때 알고 싶은 사실을 그대로 말하겠다”고 선언한다.

## How to apply

특히 위기·보고·중대 결정 메시지에는 4 줄 블록을 넣는다:

1. **아는 것** (확정 사실)
2. **모르는 것** (현재 데이터가 없는 영역)
3. **확인 중인 것** (조사 중 항목 + 담당자)
4. **다음 업데이트 시점** (구체 일시)

추가 원칙
- 나쁜 소식은 늦지 않게, 가공하지 않게.
- 추정·예측은 “추정” 표시. 사실처럼 말하지 않는다.
- 자신감 표현(probably / 거의 확실 / 가능성 있음)을 일관되게 쓴다.

## Checklist

- [ ] 메시지에 “아는 것 / 모르는 것 / 확인 중 / 다음 업데이트”가 분리됨
- [ ] 불리한 정보도 포함되어 있다
- [ ] 추정과 사실이 언어적으로 구분된다
