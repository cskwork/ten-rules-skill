# Rule 05 — AVM Transparency and Confidence Communication

> 자동 평가액은 추정값이지 사실이 아니다 — 신뢰 구간과 데이터 출처를 반드시 함께 표시하라.
> An automated valuation is an estimate, not a fact — always display a confidence range and the data sources alongside the number.

## Why

Automated Valuation Models (AVMs) carry meaningful error rates: Zillow's Zestimate median error is 2.4% for on-market homes but 6.9% for off-market properties; in thin-data markets, errors exceed 20%. Displaying a single authoritative-looking price without communicating uncertainty leads consumers to anchor incorrectly, make lowball offers, or skip professional appraisals. Lenders using AVM tools for origination are subject to Interagency Appraisal and Evaluation Guidelines (OCC/FDIC/Fed); consumer-facing portals that imply appraisal-grade precision without the regulatory infrastructure face FTC deceptive-practices risk. The AVM must be positioned as a starting point, not a substitute for a licensed appraisal.

## How to apply

- Display AVM estimates as a range (e.g., "$480,000 – $530,000 estimated value") rather than a single figure; derive the range from the model's confidence interval or standard error.
- Show the "data freshness" of the AVM inputs: last sale date used, number of comparables, and the date the estimate was generated.
- Include a one-sentence disclaimer that the estimate is generated by an algorithm, is not an appraisal, and may differ materially from appraised or market value.
- Provide a "How was this calculated?" expandable section that names the primary data sources (MLS sales, tax assessments, public records) and the general methodology (hedonic regression, machine learning) without requiring users to understand the math.
- Do not display AVM estimates for property types where the model has insufficient comparables (fewer than 3 comparables within 0.5 miles in 12 months); show "Insufficient data for estimate" instead.

## Checklist

- [ ] AVM output is displayed as a range, not a single point estimate.
- [ ] Estimate page shows input data freshness: last comparable sale date and count.
- [ ] Disclaimer text is present and legible (not hidden in footer fine print).
- [ ] "How calculated" section names data sources and general methodology.
- [ ] Properties below comparable threshold show "Insufficient data" instead of an estimate.
