# Rule 08 — Evaluate Against the 10 Usability Heuristics

> 사용자가 없을 때는 닐슨의 10대 휴리스틱으로 점검하라.
> When users are unavailable, inspect the interface against Nielsen's 10 usability heuristics.

## Why

Jakob Nielsen's 10 Usability Heuristics (first published 1994; last substantively updated by NN/G in 2020) are the field's default inspection standard for surfacing problems without a full user test. They cover visibility of system status, match to the real world, user control and freedom, consistency, error prevention, recognition over recall, flexibility, minimalist design, helping users recover from errors, and help and documentation. A heuristic evaluation complements, not replaces, user testing.

## How to apply

- Have 2 to 5 evaluators independently walk the interface against all 10 heuristics.
- Log each violation with the heuristic it breaks and a severity rating.
- Use heuristic review to catch obvious issues cheaply before spending user sessions.
- Reconcile evaluators' findings into one prioritized list after independent passes.
- Treat heuristics as rules of thumb, not laws; confirm questionable calls with users.

## Checklist

- [ ] All 10 heuristics were applied, not a favorite subset
- [ ] Each issue is tagged to a heuristic and given a severity
- [ ] 2 to 5 evaluators reviewed independently, then reconciled
- [ ] Heuristic findings are paired with, not substituted for, user testing
