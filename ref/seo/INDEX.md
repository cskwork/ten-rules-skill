# Search Engine Optimization — 10 Rules (index)

Source: market-researched synthesis grounded in Google Search Essentials (formerly Webmaster Guidelines), the Google Search Quality Rater Guidelines + E-E-A-T, the schema.org structured data vocabulary, and Core Web Vitals (web.dev). SEO is the practice of making content discoverable, understandable, and trustworthy to search engines so it ranks for the queries real people use, without manipulative tactics.

Pick the rules that bear on the task, then open those files for the full Why / How / Checklist.

| # | File | Principle | Read when the task touches |
|---|------|-----------|----------------------------|
| 01 | `01-people-first-content.md` | Create helpful, people-first content | Writing, planning, or auditing any page |
| 02 | `02-match-search-intent.md` | Match the searcher's intent | Keyword choice, page type, content briefs |
| 03 | `03-crawlability-indexing.md` | Make pages crawlable and indexable | New sites, migrations, indexing problems |
| 04 | `04-eeat-trust.md` | Demonstrate E-E-A-T and trust | YMYL topics, authorship, credibility |
| 05 | `05-on-page-optimization.md` | Optimize titles, headings, and on-page signals | Page-level copy, metadata, headings |
| 06 | `06-avoid-manipulative-tactics.md` | Avoid spam and manipulative tactics | Link building, scaled content, risk review |
| 07 | `07-internal-linking-structure.md` | Build clear structure and internal links | Site architecture, navigation, URL design |
| 08 | `08-core-web-vitals.md` | Meet Core Web Vitals and page experience | Performance, layout shift, responsiveness |
| 09 | `09-structured-data.md` | Add valid structured data | Rich results, entity markup, product/article |
| 10 | `10-measure-and-iterate.md` | Measure, monitor, and iterate | Reporting, regressions, ongoing optimization |

Default for "optimizing a single web page for organic search": read 01, 02, 05 at minimum (add 04 for any YMYL topic).
