# Rule 07 — Build Clear Structure and Internal Links

> 구조가 곧 지도다. 길을 잃으면 색인도 길을 잃는다.
> Structure is the map; if users get lost, so does the index.

## Why

Google discovers pages and understands their relationships by following internal links, and descriptive anchor text tells Google what the linked page is about. A logical hierarchy and consistent URL patterns help engines infer page type and distribute authority to important pages. Misaligned links — informational anchors pointing at a transactional page — dilute intent signals. Clear structure improves both crawl efficiency and the searcher's path.

## How to apply

- Organize the site into a shallow, logical hierarchy grouped by topic.
- Link related pages with descriptive, intent-matched anchor text.
- Point internal links to the most important pages to concentrate authority.
- Keep URL patterns consistent so structure reflects page type (for example, `/blog/` for articles).
- Add breadcrumbs to clarify location and reinforce hierarchy.

## Checklist

- [ ] The site uses a shallow, topic-based hierarchy
- [ ] Anchor text is descriptive and matches the target page's intent
- [ ] Key pages receive internal links from relevant content
- [ ] URL patterns consistently reflect page type
- [ ] Breadcrumbs reflect the page's place in the hierarchy
