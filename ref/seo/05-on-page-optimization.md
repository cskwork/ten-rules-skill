# Rule 05 — Optimize Titles, Headings, and On-Page Signals

> 페이지가 무엇에 관한 것인지 명확히 말하라.
> State plainly what the page is about.

## Why

Google Search Essentials instructs you to use the words people search for and place them in prominent locations — the title element and main headings. These signals tell both engines and readers what a page covers and shape the result snippet. Clear, unique, descriptive titles and a logical heading hierarchy improve relevance and click-through. This is the lowest-effort, highest-leverage page-level work after content and intent are right.

## How to apply

- Write a unique, descriptive `<title>` that leads with the page's primary topic.
- Use one clear `<h1>` and a logical `<h2>`/`<h3>` outline that reflects content structure.
- Write a meta description that accurately summarizes the page to earn the click.
- Use descriptive, human-readable URLs that signal the page topic.
- Add descriptive `alt` text to meaningful images.

## Checklist

- [ ] The title is unique across the site and describes the page accurately
- [ ] Exactly one H1, with a logical H2/H3 hierarchy below it
- [ ] The meta description summarizes the page and reads naturally
- [ ] URLs are readable and topic-descriptive
- [ ] Meaningful images carry descriptive alt text
