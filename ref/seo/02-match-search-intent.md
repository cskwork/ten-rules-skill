# Rule 02 — Match the Searcher's Intent

> 키워드가 아니라 의도에 답하라.
> Answer the intent behind the query, not just the keyword.

## Why

Google ranks the pages that best satisfy what the user actually wants, not those that merely contain the keyword. A query carries intent — informational, navigational, commercial, or transactional — and a mismatch (a product page for an informational query) loses regardless of technical quality. Intent alignment determines page type, format, and depth. Inspecting the current top results reveals the intent Google has already validated for that query.

## How to apply

- Classify each target query by intent before choosing a page type.
- Inspect the current top-ranking results; let the dominant format guide yours (guide, list, product, comparison).
- Match content depth and format to intent — a how-to needs steps, a comparison needs a table.
- Use the words your audience uses; place them in the title and main headings.
- Map one primary intent per URL; do not force multiple conflicting intents onto one page.

## Checklist

- [ ] Each target query is labeled with its primary intent
- [ ] The page format matches the format that already ranks for that query
- [ ] One page serves one primary intent, not several conflicting ones
- [ ] The audience's actual phrasing appears in title and headings
- [ ] The page satisfies the query without a follow-up search
