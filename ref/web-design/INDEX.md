# Web Design — 10 Rules (index)

Source: `github.com/cskwork/web-design-10-rules`. Award-worthy web design
(Awwwards/Webby/CSSDA/D&AD + Norman/Krug/Nielsen/Rams).

Pick the rules that bear on the task, then open those files for the full Why / How / Checklist.

| # | File | Principle | Read when the task touches |
|---|------|-----------|----------------------------|
| 01 | `01-user-purpose.md` | Every screen starts from the user's purpose | page goals, IA, what a page is *for* |
| 02 | `02-instant-clarity.md` | First 5s show what/why/next-action | hero, above-the-fold, first impression |
| 03 | `03-visual-hierarchy.md` | Hierarchy is information structure before beauty | layout, type scale, emphasis, scanning |
| 04 | `04-content-as-design.md` | Content is the design, not filler | copy, real data, empty/edge states |
| 05 | `05-consistency.md` | Consistency is the basis of trust | design system, components, patterns |
| 06 | `06-clear-interaction.md` | Interactions: discoverable, feedback, reversible | buttons, forms, controls, affordances |
| 07 | `07-purposeful-motion.md` | Motion guides and sets emotion, not decoration | animation, transitions, scroll effects |
| 08 | `08-accessibility.md` | Accessibility is a baseline, not an option | contrast, keyboard, ARIA, semantics |
| 09 | `09-performance.md` | Performance is a design decision | images, fonts, video, Core Web Vitals |
| 10 | `10-brand-memory.md` | Differentiation builds memorable brand structure | identity, tone, signature moments |

Default for "build/review a page": read 01, 02, 03, 08, 09 at minimum.
