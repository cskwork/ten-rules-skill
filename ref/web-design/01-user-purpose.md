# Rule 01 — User Purpose First

> 모든 화면은 “사용자 목적”에서 시작해야 한다.

## Why

좋은 웹사이트는 페이지를 장식 단위가 아닌 **사용자 과업 단위**로 본다. GOV.UK Design Principles 도 “Start with user needs” 를 1번 원칙으로 명시한다. 가정이 아니라 조사·데이터·실사용자 대화에서 출발해야 한다.

## How to apply

- 한 페이지 = 한 주목적.
- 페이지 시작 전, 3가지를 적는다.
  1. 이 사용자는 누구인가
  2. 무엇을 이해해야 하는가
  3. 다음 행동은 무엇인가
- 랜딩: 브랜드 이해 → 신뢰 → 행동.
- 제품 페이지: 문제 인식 → 해결 방식 → 증거 → 구매/문의.
- “예쁘게 보이지만 사용자 목적이 흐려진다”면 제거 대상.

## Checklist

- [ ] 한 페이지에 단일 주목적이 정의되어 있다
- [ ] 사용자 니즈가 가정이 아닌 데이터/리서치 기반이다
- [ ] 장식 요소가 핵심 과업을 방해하지 않는다
