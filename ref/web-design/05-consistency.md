# Rule 05 — Consistency

> 일관성은 지루함이 아니라 신뢰의 기반이다.

## Why

Nielsen 휴리스틱: 사용자가 같은 단어·상황·행동이 같은 의미인지 고민하지 않아야 한다. GOV.UK 원칙: “Be consistent, not uniform.” — 동일성이 아니라 예측 가능성이다.

## How to apply

- 디자인 토큰화: color / spacing / radius / shadow / typography 를 변수로 관리.
- 컴포넌트 라이브러리: 버튼·링크·폼·카드·모달·알림·아이콘 단일 소스.
- 인터랙션 규칙: hover / focus / active / disabled 상태가 컴포넌트 단위로 동일.
- 플랫폼 관습 존중 — 사용자는 다른 사이트의 경험을 들고 온다.
- 변주는 규칙을 정한 뒤에만 한다.

## Checklist

- [ ] 색 / 간격 / 타이포 / 라운드 / 그림자가 토큰으로 정의됨
- [ ] 동일 역할의 컴포넌트가 한 가지 모양으로 통일
- [ ] hover / focus / active / disabled 상태가 일관
