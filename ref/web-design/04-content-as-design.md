# Rule 04 — Content Is Design

> 콘텐츠는 디자인의 재료가 아니라 디자인 자체다.

## Why

Awwwards 는 Content 를 10% 별도 항목으로 평가하고, Webby 도 Content 를 핵심 기준에 포함한다. 사용자는 “멋진 레이아웃”이 아니라 자신에게 필요한 의미를 얻으러 온다.

## How to apply

- “우리가 무엇을 한다”보다 “사용자가 어떤 문제를 해결한다”가 앞.
- 짧은 문장, 명확한 제목, 맥락 있는 이미지, 증거 자료(로고 / 수치 / 사례).
- 마이크로카피(버튼 라벨, 빈 상태, 오류 메시지)도 디자인이다.
- 와이어프레임 단계에서 더미 텍스트(Lorem ipsum) 금지 — 진짜 카피로 검증.
- 콘텐츠 우선순위 = 시각 우선순위.

## Checklist

- [ ] 모든 카피가 사용자 가치 중심으로 작성됨
- [ ] 빈 상태 / 오류 / 로딩 카피까지 정의되어 있음
- [ ] 더미 텍스트 없이 실제 콘텐츠로 검증함
