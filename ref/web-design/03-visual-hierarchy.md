# Rule 03 — Visual Hierarchy

> 시각 계층은 아름다움보다 먼저 정보 구조다.

## Why

Webby 의 평가는 Structure & Navigation 과 Visual Design 을 함께 본다. 수상작의 공통점은 “큰 글씨”가 아니라 무엇을 먼저 보고, 어떤 행동으로 이어지는지가 시각적으로 설계된 구조다.

## How to apply

- 타이포 스케일을 먼저 잡는다 (예: 12 / 14 / 16 / 20 / 28 / 40 / 64).
- 그리드와 여백으로 리듬을 만든다 (8pt baseline 권장).
- 대비로 우선순위를 만든다 — 가장 중요한 것이 가장 강하게.
- 한 섹션 = 한 메시지 = 한 행동.
- 색은 의미 단위로만 쓴다 (primary / accent / muted / danger).

## Checklist

- [ ] 제목만 훑어도 페이지 구조가 이해된다
- [ ] CTA 가 주변 배경/요소보다 먼저 보인다
- [ ] 본문·보조 정보·장식의 위계가 명확하다
- [ ] 그리드와 여백이 일관된 리듬을 만든다
