# Rule 02 — Instant Clarity (5 seconds)

> 첫 5초 안에 “무엇인지, 왜 중요한지, 무엇을 하면 되는지” 보여줘야 한다.

## Why

Steve Krug 『Don’t Make Me Think』 의 원칙: 사용자가 해석에 머뭇거리는 순간 이탈한다. 웹은 책이 아니라 행동을 위한 표면이다.

## How to apply

첫 화면이 즉시 답해야 할 3 가지:

1. 여기는 누구/무엇의 사이트인가
2. 나에게 어떤 가치가 있는가
3. 다음에 무엇을 누르거나 읽어야 하는가

체크 도구:
- 5초 테스트 — 새 사용자에게 5초 노출 후 가린다. 3가지 질문에 답하는가.
- 히어로 카피는 “우리가 무엇을 한다”보다 “당신이 무엇을 얻는다”.
- CTA 는 1개의 1차 + 1개의 2차까지로 제한.

## Checklist

- [ ] 정체성·가치·CTA 가 스크롤 없이 보인다
- [ ] 5초 테스트 통과
- [ ] 히어로 카피가 사용자 가치 중심
