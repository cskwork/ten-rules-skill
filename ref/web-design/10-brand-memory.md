# Rule 10 — Memorable Brand

> 차별성은 트렌드 복제가 아니라 브랜드의 기억 구조를 만드는 것이다.

## Why

수상작에는 대체로 한 가지 강한 기억 장치가 있다 — 독특한 타이포, 예상 밖의 스크롤 내러티브, 고유 색 조합, 이미지 연출, 사운드, 3D 오브젝트, 카피 톤. Webby Innovation, CSS Design Awards Innovation 모두 “고유성”을 별도 축으로 평가한다.

Rams 의 “Less, but better” — 본질을 방해하지 않는 선에서 기억에 남아야 한다.

## How to apply

- 브랜드의 “기억 자산” 1~2 개를 정의: signature 컬러? 타이포? 모션? 이미지 톤? 카피 보이스?
- 트렌드(글래스모피즘·뉴모피즘·메가 카피 등)는 “복제”가 아니라 “브랜드 언어로 번역”.
- 일관된 보이스 (formal / playful / direct / poetic).
- 디테일에 시그니처를 박는다 — 커서, 로딩, 빈 상태, 404, hover.
- “이상함”이 아니라 “이 사이트답다”는 인상을 목표로.

## Checklist

- [ ] 브랜드 시그니처 자산이 1~2 개 명확히 정의됨
- [ ] 보이스 가이드라인이 존재하고 카피에 일관 적용
- [ ] 404 / 빈 상태 / 로딩까지 브랜드 디테일이 들어 있음
- [ ] 트렌드 요소가 “복제”가 아닌 “재해석”
